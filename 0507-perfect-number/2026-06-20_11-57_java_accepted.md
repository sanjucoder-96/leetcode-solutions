## Solution

```java
class Solution {
    public boolean checkPerfectNumber(int num) {
        int div=1;
           if( num <= 1)
        {
          return false;
        }
        for(int i=2;i*i<=num;i++){
            if(num%i==0){
                div+=i;
                if(num/i!=i) div+=(num/i);
            }
        }
        return div==num;
    }
}
```
