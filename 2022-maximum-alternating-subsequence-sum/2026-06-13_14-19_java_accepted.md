## Solution

```java
class Solution {
    public long maxAlternatingSum(int[] arr) {
        int n=arr.length;
        long dp[][] = new long[n+1][2];
        for(int i=1;i<=n;i++){
            // Case 1: taking current index forms an even length then till now odd length that means last index is even one as 0 based indexing so subtract arr[i-1] considering it for forming even length
            // case 2 : consider not taking this means you want to form even length without this which is stored in dp[i-1][0]
            //similarly for the odd one also 
            dp[i][0]=Math.max(dp[i-1][1]-arr[i-1],dp[i-1][0]);
            dp[i][1]=Math.max(dp[i-1][0]+arr[i-1],dp[i-1][1]);
        }
        return Math.max(dp[n][0],dp[n][1]);
    }
}
```
