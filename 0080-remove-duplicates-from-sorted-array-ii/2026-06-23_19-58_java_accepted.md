## Solution

```java
class Solution {
    public int removeDuplicates(int[] arr) {
        int k=2,n=arr.length;
        for(int i=2;i<n;i++){
            if(arr[k-2]!=arr[i]){
                arr[k]=arr[i];
                k++;
            }
        }
        return k;
    }
}
```
