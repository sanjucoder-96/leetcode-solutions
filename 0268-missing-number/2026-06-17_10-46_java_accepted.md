## Solution

```java
class Solution {
    public int missingNumber(int[] arr) {
         int n=arr.length;
       int i=0;
       while(i<n){
        int c=arr[i];
        if( arr[i]<n && arr[i]!=arr[c] ){
            int temp=arr[i];
            arr[i]=arr[c];
            arr[c]=temp;
        }
        else{
            i++;
        }
       }
       for(int l=0;l<n;l++){
        if(arr[l]!=l) return l;
       }
       return n;
    }
}
```
