## Solution

```java
class Solution {
    public int[] arrayRankTransform(int[] arr) {
        int n=arr.length;
        int[] temp = Arrays.copyOf(arr,n);
        Arrays.sort(temp);
        Map<Integer,Integer> mp = new HashMap<>();
        int count=1;
        for(int i=0;i<n;i++){
            if(!mp.containsKey(temp[i])){
            mp.put(temp[i],count);
            count++;}
        }
        int[] res = new int[n];
        for(int i=0;i<n;i++){
            res[i]=mp.get(arr[i]);
        }
        return res;
    }
}
```
