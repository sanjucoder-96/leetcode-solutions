## Solution

```java
class Solution {
    public int longestSubsequence(int[] arr) {
        int n=arr.length;
        boolean allZero=false;
        int finalXor=0;
        for(int ele : arr){
            finalXor^=ele;
            if(ele!=0)
            allZero=true;
        }
        if(!allZero) return 0;
        return finalXor!=0?n:n-1;
    }
}
```
