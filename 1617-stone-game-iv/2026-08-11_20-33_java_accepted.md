## Solution

```java
class Solution {
    Boolean[] dp;

    public boolean winnerSquareGame(int n) {
        dp= new Boolean[n+1];
        Arrays.fill(dp,false);
        dp[0]=false;
        for(int i=1;i<=n;i++){
            for(int k=1;k*k<=i;k++){
            if(!dp[i-(k*k)])  {
                dp[i]=true; 
                break;
        }

        }
    }
        return dp[n];
}
}
```
