## Solution

```java
class Solution {
    public long maxSum(int[] arr, int k, int mul) {
        int n=arr.length;
        Arrays.sort(arr);
        int i=n-1;long res=0;
        while(k>0){
            if(mul>0){
                res+=arr[i]*1L* mul;
                mul--;
            }
            else{
                res+=arr[i];
            }
            i--;
            k--;
        }
        return res;
    }
}
```
