## Solution

```java
class Solution {
    public long countMajoritySubarrays(int[] arr, int target) {
        long res=0;
        int sum=0;
        Map<Integer,Integer> mp = new HashMap<>();
        mp.put(0,1);
        long validLeftPoints=0;
        for(int ele : arr){
            if(ele==target){
                validLeftPoints+=mp.getOrDefault(sum,0);
                sum++;
            }
            else{
                sum--;
                validLeftPoints-=mp.getOrDefault(sum,0);
            }
            mp.put(sum,mp.getOrDefault(sum,0)+1);
                res+=validLeftPoints;
        }
        return res;
    }
}
```
