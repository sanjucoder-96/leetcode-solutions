## Solution

```java
class Solution {
    public int lastStoneWeight(int[] stones) {
        int n=stones.length;
        PriorityQueue<Integer> pq = new PriorityQueue<>(Comparator.reverseOrder());
        for(int ele : stones){
         pq.add(ele);
        }
        while(pq.size()>1){
            int a=pq.poll();
            int b=pq.poll();
            if(a!=b) pq.add(a-b);
        }
        return pq.peek()!=null?pq.peek():0;

    }
}
```
