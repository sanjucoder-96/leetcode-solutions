## Solution

```java
class Solution {
    public int largestAltitude(int[] gain) {
        int sum=0,max=Integer.MIN_VALUE;
        for(int ele : gain){
            max=Math.max(sum,max);
            sum+=ele;
        }
            max=Math.max(sum,max);
        return max;
    }
}
```
