## Solution

```java
class Solution {
    public int maxProduct(int n) {
        String num=String.valueOf(n);
        int max=0;
        for(int i=0;i<num.length();i++){
            for(int j=i+1;j<num.length();j++){
                max=Math.max(max,(num.charAt(i)-'0')*(num.charAt(j)-'0'));
            }
        }
        return max;
    }
}
```
