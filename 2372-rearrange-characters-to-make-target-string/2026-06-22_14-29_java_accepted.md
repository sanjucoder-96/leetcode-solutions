## Solution

```java
class Solution {
    public int rearrangeCharacters(String s, String target) {
        int n=target.length();
    char freqReq[] = new char[26];
    char freqavial[] = new char[26];
    for(char c : target.toCharArray()){
        freqReq[c-'a']++;
    }

    for(char c : s.toCharArray())
        freqavial[c-'a']++;
    int min=Integer.MAX_VALUE;
    for(char c : target.toCharArray())
    {
        min=Math.min(min,freqavial[c-'a']/freqReq[c-'a']);
    }
    return min;
    }
}
```
