## Solution

```java
class Solution {
    
    public int longestPalindrome(String s) {
        int n=s.length(),maxLen=0;
        Set<Character> st = new HashSet<>();
        for(char c : s.toCharArray()){
            if(st.contains(c)){
                maxLen+=2;
                st.remove(c);
            }
            else st.add(c);
        }

        return (!st.isEmpty())?maxLen+1:maxLen;
    }
}
```
