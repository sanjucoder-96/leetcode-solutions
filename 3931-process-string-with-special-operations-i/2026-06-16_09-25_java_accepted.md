## Solution

```java
class Solution {
    public String processStr(String s) {
        int n=s.length();
        StringBuilder res = new StringBuilder();
        for(char c: s.toCharArray()){
            if(Character.isLowerCase(c)){
                res.append(c);
            }
            else if(c=='*' && res.length()>0){
                res.deleteCharAt(res.length()-1);
            }
            else if(c=='#'){
                res.append(res);
            }
            else {
                res.reverse();
            }
        }
            return res.toString();
    }
}
```
