## Solution

```java
class Solution {
    public int removeDuplicates(int[] arr) {
        int n=arr.length;
        int unq=00;
        for(int i=0;i<n;i++){
            if(arr[unq]!=arr[i]) {
                unq++;
                arr[unq]=arr[i];
            }
        }
        return unq+1;
    }
}
```
