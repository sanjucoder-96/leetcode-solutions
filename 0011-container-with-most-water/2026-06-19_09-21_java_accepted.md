## Solution

```java
class Solution {
    public int maxArea(int[] arr) {
        int n=arr.length;
        int max=Integer.MIN_VALUE;
        int l=0,r=n-1;
        while(l<=r){
            int min=Math.min(arr[l],arr[r]);
            
            max=Math.max((r-l)*min,max);
            if(arr[l]<arr[r]) l++;
            else r--;
        }
        return max;
    }
}
```
