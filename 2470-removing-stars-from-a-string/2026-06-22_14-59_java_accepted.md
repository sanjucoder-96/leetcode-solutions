## Solution

```java
class Solution {
    public String removeStars(String s) {
        Deque<Character> dq = new ArrayDeque<>();
        for(char c : s.toCharArray()){
            if(c=='*') {
                dq.pop();}
            else
            dq.push(c);
        }
        StringBuilder sb = new StringBuilder();
        while(!dq.isEmpty()){
            sb.append(dq.pop());
        }
        return sb.reverse().toString();
    }
}
```
