## Solution

```java
class Solution {
    public int removeElement(int[] arr, int val) {
        int k=0,n=arr.length;
        for(int i=0;i<n;i++){
            if(arr[i]!=val){
                arr[k]=arr[i];
                k++;
            }
        }
        return k;
    }
}
```
