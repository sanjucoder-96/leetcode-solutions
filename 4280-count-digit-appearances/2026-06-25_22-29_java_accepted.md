## Solution

```java
class Solution {
    public int countDigitOccurrences(int[] arr, int digit) {
        int n=arr.length;
        int c=0;
        for(int ele : arr){
            int temp=ele;
            while(temp>0){
                int dig=temp%10;
                if(dig==digit) c++;
                temp/=10;
            }
        }
        return c;
    }
}
```
