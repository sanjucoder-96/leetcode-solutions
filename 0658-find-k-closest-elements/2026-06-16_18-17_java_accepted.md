## Solution

```java
class Solution {
     public List<Integer> findClosestElements(int[] arr, int k, int x) {
        List<Integer> res = new ArrayList<>();
         PriorityQueue<Integer> pq = new PriorityQueue<>(Comparator.comparing((Integer a)->Math.abs(a-x)).thenComparingInt( a->a));
        for(int ele : arr){
            pq.add(ele);
        }
        while(!pq.isEmpty() && res.size()<k){
            res.add(pq.poll());
        }
        Collections.sort(res);
        return res;
    }
}
```
