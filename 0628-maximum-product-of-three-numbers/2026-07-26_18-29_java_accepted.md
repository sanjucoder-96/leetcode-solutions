## Solution

```java
class Solution {
    public int maximumProduct(int[] nums) {
        Arrays.sort(nums);
        int n=nums.length;
        int res=nums[n-1];
        int max=Integer.MIN_VALUE;
        for(int i=0;i<n-1;i++){
            for(int j=i+1;j<n-1;j++){
                max=Math.max(max,res*nums[i]*nums[j]);
            }
        }
        return max;
    }
}
```
