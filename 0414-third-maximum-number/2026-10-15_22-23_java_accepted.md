## Solution

```java
class Solution {
    public int thirdMax(int[] nums) {
        TreeSet<Integer> st = new TreeSet<>();
        for(int ele : nums) st.add(ele);
        List<Integer> res = new ArrayList<>(st);
        if(res.size()==1)
        return res.get(0);
        else if(res.size()==2)
        return res.get(1);
        return res.get(st.size()-3);
    }
}
```
