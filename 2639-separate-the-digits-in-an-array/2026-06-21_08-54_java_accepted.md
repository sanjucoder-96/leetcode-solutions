## Solution

```java
class Solution {
    public int[] separateDigits(int[] nums) {
        
        List<Integer> res = new ArrayList<>();
       for(int i=nums.length-1;i>=0;i--){
        int temp=nums[i];
        while(temp>0){
            int dig=temp%10;
            res.add(dig);
            temp/=10;
        }
       }

       Collections.reverse(res);
       int[] arr= new int[res.size()];
       for(int j=0;j<res.size();j++)
       arr[j]=res.get(j);
       return arr;
    }
}
```
