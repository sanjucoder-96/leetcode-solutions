## Solution

```java
class Solution {
    public double solve(double a, int n) {
        if (n == 0)
            return 1;
        double halfPower = solve(a, n / 2);
        double halfPower2 = halfPower * halfPower;
        if ((n & 1) == 1)
            return a * halfPower2;
        return halfPower2;
    }

    public double myPow(double x, int n) {
        if (n < 0)
            return solve(1 / x, n);
        return solve(x, n);
    }
}
```
