## Solution

```java
class Solution {
    public int calc(int a, int b) {
    if (b == 0) return a;
    return calc(b, a % b);
}

public int findGCD(int[] arr) {
    int gcd = 0;
    int max=0,min=10001;
    for(int ele : arr){
        min=Math.min(ele,min);
        max=Math.max(ele,max);
    }
    return calc(min,max);
}

}
```
