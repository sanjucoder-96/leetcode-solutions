## Solution

```java
class Solution {
    public int minimumPushes(String word) {
          int[] mp = new int[26];
       for(char c : word.toCharArray()){
        mp[c-'a']++;
       }
Arrays.sort(mp);
    for(int i=0;i<13 ;i++){
        int temp=mp[26-1-i];
        mp[26-i-1]=mp[i];
        mp[i]=temp;
    }
       int count=0;
       for(int i=0;i<26;i++){
            int freq=mp[i];
            int presses= i/8 + 1 ;
            count+= freq*presses;

       }
       return count;
    }
}
```
