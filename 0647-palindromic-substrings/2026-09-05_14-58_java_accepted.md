## Solution

```java
class Solution {
    public int countSubstrings(String str) {
        int n=str.length();
        char[] s= str.toCharArray();
        boolean[][] dp = new boolean[n][n];
        int count=0;
        for(int len=1;len<=n;len++){
            for(int i=0;i+len-1<n;i++){
                int j=i+len-1;
                if(i==j){
                    dp[i][i]=true;
                }
                else if(i+1==j){
                    dp[i][j]=(s[i]==s[j]);
                }
                else{
                    dp[i][j]=(s[i]==s[j] && dp[i+1][j-1]);
                }

                count+=(dp[i][j])?1:0;
            }
        }
        return count;
    }
}
```
