## Solution

```java
class Solution {
    public int countSquares(int[][] arr) {
        int m=arr.length;
        int n=arr[0].length;
        for(int i=1;i<m;i++){
            for(int j=1;j<n;j++){
                if(arr[i][j]==1)
                arr[i][j]=arr[i][j]+Math.min(arr[i-1][j],Math.min(arr[i][j-1],arr[i-1][j-1]));
            }
        }
        int s=0;
        for(int[] r : arr){
            for(int ele : r)
            s+=ele;
        }
        return s;
    }
}
```
