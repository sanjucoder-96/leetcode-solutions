## Solution

```java
class Solution {
    public static int[] dailyTemperatures(int[] temperatures) {
        int n=temperatures.length;
        int[] res = new int[n];
        Deque<Integer> st = new ArrayDeque<>();

        for(int i=n-1;i>=0;i--){
            while(!st.isEmpty() && temperatures[i]>=temperatures[st.peek()])
                st.pop();
            res[i]=st.isEmpty()?0:Math.abs(i-st.peek());
            st.push(i);
        }
        return res;
    }

}
```
