## Solution

```java
class Solution {
    public int minSwaps(int[] arr){
        int res=0;
        int n=arr.length;
       
        boolean[] visited = new boolean[n];
        for(int i=0;i<n;i++){
            if(visited[i]) continue;
            int j=i,len=0;
            while(!visited[j]){
                visited[j]=true;
                j=arr[j];
                len++;
            }
            res=Math.max(len,res);
        }
        return res;
    }
    public int arrayNesting(int[] nums) {
        return minSwaps(nums);
    }
}
```
