## Solution

```java
class Solution {
    public int[] sortArray(int[] arr) {
        int n=arr.length;
        PriorityQueue<Integer> pq = new PriorityQueue<>((a,b)->(a-b));
        for(int ele : arr)
        pq.add(ele);

        int k=0;
        while(!pq.isEmpty()){
            arr[k++]=pq.poll();
        }
        return arr;
    }
}
```
