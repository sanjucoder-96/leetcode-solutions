## Solution

```java
class Solution {
    public int countGoodTriplets(int[] arr, int a, int b, int c) {
        int n=arr.length,count=0;
        for(int i=0;i<n;i++){
            for(int j=i+1;j<n;j++){
                for(int k=j+1;k<n;k++){
                    int aDist=Math.abs(arr[i]-arr[j]);
                    int bDist=Math.abs(arr[j]-arr[k]);
                    int cDist=Math.abs(arr[i]-arr[k]);
                    if(aDist<=a && bDist<=b && cDist<=c) count++;
                }
            }

        }
        return count;
    }
}
```
