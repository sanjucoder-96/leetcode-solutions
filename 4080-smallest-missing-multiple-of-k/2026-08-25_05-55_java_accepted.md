## Solution

```java
class Solution {
    public int missingMultiple(int[] nums, int k) {
        Set<Integer> st = new HashSet<>();
        for(int ele : nums) st.add(ele);
        int i=k;
        while(st.contains(i)){
            i+=k;
        }
        return i;
    }
}
```
