## Solution

```java
class Solution {
    public long sumAndMultiply(int n) {
        long temp=(int)n;
        long res=0;
        long sum=0;
        while(temp>0){
            long dig=temp%10;
            if(dig!=0){
                res=res*10+dig;
            }
            sum+=dig;
            temp/=10;
        }  
        temp=res;
        long rev=0;
        while(temp>0){
            rev=rev*10+temp%10;
            temp/=10;
        }

         return sum*rev;
        
    }
}
```
