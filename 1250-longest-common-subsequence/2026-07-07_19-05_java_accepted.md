## Solution

```java
class Solution {
   
    public int longestCommonSubsequence(String s, String t) {
        int n=s.length(),m=t.length();
        int[][] dp = new int[n+1][m+1];
        for(int i=1;i<=n;i++)
        {
            for(int j=1;j<=m;j++){
                int take=0,skip=0;
                if(s.charAt(i-1)==t.charAt(j-1)){
                    take=1+dp[i-1][j-1];
                }
                else{
                        
                        skip=Math.max(dp[i-1][j],dp[i][j-1]);
                }
                dp[i][j]=Math.max(take,skip);
            }
        }
         return dp[n][m];
    }
}
```
