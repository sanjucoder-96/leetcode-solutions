## Solution

```java
class Solution {
    public int maximumLengthSubstring(String s) {
        Map<Character,Integer> mp = new HashMap<>();
        int i=0;
        int n=s.length();
        int max=0;
        for(int j=0;j<n;j++){
            char c =s.charAt(j);
            mp.put(c,mp.getOrDefault(c,0)+1);
            while(mp.getOrDefault(c,0)>2){
                mp.computeIfPresent(s.charAt(i),(k,v)->v>1?v-1:null);
                i++;
            }

            max=Math.max(max,j-i+1);
        }
        return max;
    }
}
```
