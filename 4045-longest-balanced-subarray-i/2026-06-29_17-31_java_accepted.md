## Solution

```java
class Solution {
    public int longestBalanced(int[] arr) {
        int n=arr.length;
        int len=0;
        Set<Integer> st,odd;
        for(int i=0;i<n;i++)
        {   st=  new HashSet<>();
         odd = new HashSet<>();
            for(int j=i;j<n;j++){
                if(arr[j]%2==0) st.add(arr[j]);
                else
                odd.add(arr[j]);

                if(odd.size()==st.size()) len=Math.max(len,j-i+1);
            }
            
        }
        return len;
    }
}
```
