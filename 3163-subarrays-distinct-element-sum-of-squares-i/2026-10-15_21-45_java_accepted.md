## Solution

```java
class Solution {
    public int sumCounts(List<Integer> nums) {
        int n=nums.size();
        int res=0;
        for(int i=0;i<n;i++){
            Set<Integer> st = new HashSet<>();
            for(int j=i;j<n;j++){
                st.add(nums.get(j));
            res+=st.size()*st.size();
            }
        }
        return res;
    }
}
```
