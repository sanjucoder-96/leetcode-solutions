## Solution

```java
class Solution {
    public boolean checkGoodInteger(int n) {
        int temp=n;
        int a=0,b=0;
        while(temp>0){
            int dig=(temp%10);
            a+=dig;
            b+=dig*dig;
            temp/=10;
       }
       return b-a>=50;
    }
}
```
