## Solution

```java
class Solution {
    public int maxValidPairSum(int[] arr, int k) {
        int n=arr.length;
        int max=0;
        int max_i=arr[0];
        for(int j=k;j<n;j++){
            max_i=Math.max(max_i,arr[j-k]);
            max=Math.max(arr[j]+max_i,max);
                
        }
        return max;
        
    }
}
```
