## Solution

```java
class Solution {
    public int firstUniqChar(String s) {
        int n=s.length();
        Queue<Character> q = new LinkedList<>();
        Map<Character,Integer> mp = new HashMap<>();
        for(char c : s.toCharArray()) {mp.put(c,mp.getOrDefault(c,0)+1);
        q.offer(c);}
            int c=0;
        while(!q.isEmpty()){
            if(mp.get(q.peek())==1) return c;
            q.remove();
            c++;
        }
        return -1;
    }
}
```
