## Solution

```java
class Solution {
    public int lengthOfLIS(int[] arr) {
        int n=arr.length;
        if(n==1) return 1;
        int[] dp = new int[n];
        int  max=0;
        for(int i=0;i<n;i++){
            dp[i]+=1;
            for(int j=0;j<i;j++){
                if(arr[j]<arr[i]){
                        dp[i]=Math.max(dp[i],1+dp[j]);
                }
                max=Math.max(dp[i],max);
            }
        }
        return max;
    }
}
```
