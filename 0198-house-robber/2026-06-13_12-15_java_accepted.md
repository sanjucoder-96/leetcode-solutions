## Solution

```java
class Solution {
    public int rob(int[] arr) {
        int n=arr.length;
        if(n<=1) return arr[0];
        int[] dp = new int[n+1];
        dp[0]=arr[0];
        dp[1]=Math.max(arr[1],dp[0]);
        for(int i=2;i<n;i++){
            int take=dp[i-2]+arr[i];
            int skip=dp[i-1];
            dp[i]=Math.max(skip,take);
            
        }
        return dp[n-1];
    }
}
```
