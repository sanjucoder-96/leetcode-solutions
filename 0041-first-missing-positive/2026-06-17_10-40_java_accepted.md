## Solution

```java
class Solution {
    public  int firstMissingPositive(int[] arr) {
        int n=arr.length;
       int i=0;
       while(i<n){
        int c=arr[i]-1;
       
        if(arr[i]>0  && arr[i]<=n && arr[i]!=arr[arr[i]-1]){
            int temp=arr[i];
            arr[i]=arr[c];
            arr[c]=temp;
        }
        else{
            i++;
        }
       }
       for(int l=0;l<n;l++){
        if(arr[l]!=l+1) return l+1;
       }
       return n+1;
    }
}
```
