## Solution

```java
class Solution {
    public double angleClock(int hour, int minutes) {
        double h_ang=30*hour + 0.5*minutes;
        double m_ang=minutes*6;
        double diff=Math.abs(h_ang-m_ang);
        return Math.min(diff,360-diff);
       
    }
}
```
