## Solution

```java
class Solution {
    public void solve(int o,int c ,int n,List<String> res, String s){
        if(s.length()==2*n){
            res.add(s);
            return ;
        }
        if(o<n)
        solve(o+1,c,n,res,s+"(");

        if(c<o)
        solve(o,c+1,n,res,s+")");
        
        
    }

    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        solve(0,0,n,res,"");
        return res;
    }
}
```
