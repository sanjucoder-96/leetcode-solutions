## Solution

```java
class Solution {
    public int[] nextGreaterElements(int[] arr) {
        int n=arr.length;
        Deque<Integer> st = new ArrayDeque<>();
        int[] res = new int[n];
        for(int i=2*n-1;i>=0;i--){
            while(!st.isEmpty() && arr[i%n]>=arr[st.peek()])
            st.pop();
            res[i%n]=(st.isEmpty())?-1:arr[st.peek()];
            st.push(i%n);
        }
        return res;
    }
}
```
