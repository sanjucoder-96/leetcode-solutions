## Solution

```java
class Solution {
    public String largestNumber(int[] arr) {
        int n=arr.length;
        
        StringBuilder sb  = new StringBuilder();
        Arrays.stream(arr).mapToObj(String::valueOf).sorted((a,b)->((b+a).compareTo(a+b))).forEach(sb::append);
    return (sb.charAt(0)=='0' && n>1) ? "0":sb.toString();
    }
}
```
