## Solution

```java
class Solution {
    public int[] getConcatenation(int[] nums) {
        int n=nums.length;
        int[] res = new int[n<<1];
        for(int i=0;i<n;i++){
            res[i]=nums[i];
            res[i+n]=nums[i];
        }
        return res;
    }
}
```
