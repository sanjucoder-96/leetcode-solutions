## Solution

```java
class Solution {
    public int steal(int[] arr,int i,int j){
        int n=(j-i+1);
        int[] dp = new int[n];
                if (n == 1) return arr[i];

        dp[0]=arr[i];
        dp[1]=Math.max(arr[i+1],dp[0]);
        for(int k=2;k<n;k++){
            dp[k]=Math.max(dp[k-1],dp[k-2]+arr[i+k]);
        }
        return dp[n-1];
    }
    public int rob(int[] nums) {
        int n=nums.length;
        if(n==1) return nums[0];
        return Math.max(steal(nums,0,n-2),steal(nums,1,n-1));
    }
}
```
