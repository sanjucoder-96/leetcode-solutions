## Solution

```java
class Solution {
    public String mapWordWeights(String[] words, int[] weights) {
        StringBuilder sb = new StringBuilder(words.length);
        for(String s: words){
            int temp=0;
            for(int i=0;i<s.length();i++){
                    temp+=weights[s.charAt(i)-'a'];
            }
            sb.append((char)('z'-(temp%26)));
        }
        return sb.toString();
    }
}
```
