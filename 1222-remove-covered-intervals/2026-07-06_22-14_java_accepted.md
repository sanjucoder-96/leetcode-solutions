## Solution

```java
class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
Arrays.sort(intervals,Comparator.comparing((int[] a)->a[0]).thenComparing((int[] x)->-x[1]));
        int c=0;
       int maxEnd=-1;
        for(int[] a : intervals){
            if(maxEnd<a[1]){
                c++;
                maxEnd=a[1];
            }
            
        }
        return c;
    }
}
```
