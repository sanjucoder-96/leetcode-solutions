## Solution

```java
class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
Arrays.sort(intervals,Comparator.comparing((int[] a)->a[0]).thenComparing((int[] x)->-x[1]));
        int c=0;
       int maxEnd=-1;
      int covered = 0;


for (int[] a : intervals) {
    if (a[1] <= maxEnd)
        covered++;
    else
        maxEnd = a[1];
}

return intervals.length - covered;
    }
}
```
