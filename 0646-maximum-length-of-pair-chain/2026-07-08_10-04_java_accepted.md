## Solution

```java
class Solution {
    public int findLongestChain(int[][] pairs) {
        int n=pairs.length;
        Arrays.sort(pairs,(a,b)->Integer.compare(a[1],b[1]));
        int[] dp = new int[n];
        int max=0;
        for(int i=0;i<n;i++){
            dp[i]=1;
            for(int j=i;j>=0;j--){
                if(pairs[j][1]<pairs[i][0]){
                    dp[i]=Math.max(dp[j]+1,dp[i]);
                }
            }
            max=Math.max(dp[i],max);
        }
        return max;
    }
}
```
