## Solution

```java
class Solution {
    public List<String> topKFrequent(String[] words, int k) {
         Map<String,Integer> mp = new HashMap<>();
        for(String s : words) mp.put(s,mp.getOrDefault(s,0)+1);
        List<String> res = new ArrayList<>();
        PriorityQueue<Map.Entry<String,Integer>>  pq = new PriorityQueue<>(Comparator.comparing((Map.Entry<String,Integer> e)->e.getValue()).reversed().thenComparing(Map.Entry::getKey));
        pq.addAll(mp.entrySet());
        for (int i = 0; i < k; i++) {
            res.add(pq.poll().getKey());
        }
        return res;
    }
}
```
