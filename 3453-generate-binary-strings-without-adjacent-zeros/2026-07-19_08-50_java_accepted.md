## Solution

```java
class Solution {
    public void generate(int i,int n,int prev,String s,List<String> res){
        if(i>=n){
            res.add(s);
            return;
        }

        if(prev==-1 || s.charAt(prev)!='0')
            generate(i+1,n,i,s+"0",res);
        generate(i+1,n,i,s+"1",res);
    }
    public List<String> validStrings(int n) {
        List<String> res = new ArrayList<>();
        generate(0,n,-1,"",res);
        return res;
    }
}
```
